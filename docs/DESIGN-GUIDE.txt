Fósforo native Android design contract — Jersey 15 revision, 2026-11-12

Scope and source of truth
Implement existing features using the approved Home, BFI and Shaders mockups in
outputs/bfi-ui-prototype (the sibling approval artifact), then apply the same
components to Apps, per-app settings and Settings. The supplied FOSFORO concepts
establish composition. User subsequently requested bolder borders: use 2dp card,
inset and control borders; retain a stronger focus state. Earlier interpretations
with stretched outer panels and merged switch/navigation rows are superseded.
Preserve package dev.pako.bfi, capture/renderer/security, settings encoding,
activation tokens, deadlines, Stop and all existing compatibility validation.

Identity
The app is Fósforo; keep package dev.pako.bfi and existing stored settings so an
update preserves the installation, permissions and shader library. BFI remains
the name of the black frame insertion effect. Do not rename the GitHub repository.
Follow system light/dark. Obsidian #0B0B0F, vibrant violet #8863DC, Phosphor #FFE04A
and lavender-derived text/surfaces define the brand. Violet structures buttons,
outlines and the moving grid. Phosphor yellow fills checked switches and selected
segments; dark ink preserves contrast on those fills. Use dark amber for active
text in light mode and yellow in dark mode. Preserve all existing shapes, spacing,
scrolling and control behavior. Status must remain readable without color alone.
Home uses an accented Jersey 15 Fósforo wordmark; the adaptive icon is a purple CRT
television with yellow screen and separate monochrome layer for themed icons.
Editable SVG sources live in assets/branding. Keep the television silhouette in
Android's adaptive-icon safe region. Subtle static text glow is reserved for the
wordmark and active status in dark mode; no pulsing or extra rendering loop.
Use bundled offline Jersey 15 throughout native views. Sarah Cadigan-Fried / The
Soft Type Project Authors are credited in Settings -> About -> font credits.
Include the original SIL Open Font License 1.1 in assets/Jersey15-OFL.txt and credit
in THIRD-PARTY-NOTICES.txt. Do not fetch fonts at runtime.

Static CRT finish
The user's explicit answer 7 restored the concepts' CRT-esque finish, overriding
the decorative-finish exclusion included in answer 20. Keep the static blueprint
behind system bars/header, with subtle static scanlines, slight text shadow and
edge falloff. The finish is a native drawable, with cached tile/gradient geometry;
it never starts capture, records video, schedules animation frames or processes
another app. Do not add a WebView or a new UI/rendering framework.

Anatomy
Thin header, compact logo/title, Back on details, Settings and confirmed scoped
Restore defaults top-right (shader reset lives inside its parameter group).
The system status bar uses the same tinted grid/CRT finish as the app header.
Card-header top corners follow the inner 16dp radius, preserving the 2dp border. Equal-width columns at >=600dp; stack in narrower
windows. Columns have fixed viewports and scroll independently when necessary.
Individual boxed groups fit their contents; leave background below short groups.
No giant enclosing cards or scrollbars inside every small group. A long app or
shader list may use a bounded recycling list. Honor insets, keyboard, RTL and
large text. Main controls reserve >=48dp targets, even when drawn pills are slim.
Use about 14–16sp Jersey 15 row text, 14sp secondary/group labels and larger titles.
Use 18dp outer corners, 12dp inset corners and segmented pill controls. Keep
borders visible around group headers; header fill must not paint over the border.

Home
Left: state and configured-effect badge, full-width Start/Stop, actionable status
only, read-only pattern/shader/scope rows; separate Test effects card with compact
Start test. Right: BFI switch row then its own inset configuration row, CRT switch
row then its own inset library row. Never merge switches and links to save space.
Scope is a separate group: System wide / Selected apps segmented control, Apps
link, Resume after unlock switch. The right column may scroll on the Nova; don't
hide that constraint by shrinking targets. Resume remains repository-backed and
is not changed by Settings/BFI resets. Home has no permanent motion preview.
The real overlay continues to apply inside BFI on supported devices.

BFI and per-app editing
Left: one static square V/B tile for every individual frame, wrapping in order;
never collapse consecutive frames into a counted tile. Show actual black fraction,
reported display rate and nominal repeat rate. Explain per-app overrides outside
the diagram group. Right: numbered pairs, Add pair in the group header, visible
and black numeric steppers, independent remove action. Valid global runs remain
2–32 alternating entries of 1–120 frames. Keep invalid drafts across rotation;
never save them. Existing per-app overrides keep their two-count limits, Use
global and exclusion semantics. No per-app CRT profiles, PWM or phase calibration.
All valid edits autosave/apply through the existing repository; no Save/Done.

Shaders
Separate browser and studio screens. Start/Stop above the selector for recovery.
The browser has one bounded recycling list, never inside another scroller.
Category segments highlight
Bundled and Favourites, with remaining real categories available via More. Search
and visible recycling rows replace the old dropdown. Each row has a cached still
thumbnail rendered through the actual shader, name, bundled
indicator and an independently accessible favourite star; selected shader is also
identified by the studio parameter heading. Open a row to enter the studio.
Studio left: animated synthetic bouncing ball through the selected shader; right:
that shader's actual parameters and a clearly scoped Restore shader defaults.
Local previews require no capture consent, never auto-start global effects, and
stop animating when hidden. Avoid applying local CRT twice when live CRT covers
the app. Cached thumbnails contain synthetic pixels only, not captured screens.
Keep the validation/probe before saving
shader selection and the error/report dialogs for unsupported shaders.
Right: actual parameter names, values and ranges; compact value/slider rows.
Honor declared separator headings; otherwise use one Parameters group. Never
invent universal CRT controls. Import and Download library remain visible; Check
compatibility, Unavailable shaders and Delete downloaded shaders live in Library
management. Destructive actions still confirm and retain existing safety checks.
Screen capture consent remains required for CRT; never silently restart it.

Apps and Settings
Apps: scope/default overview left, inline searchable installed-app list right.
Rows retain icons, Default/Custom pattern status, separate selection checkbox and
edit chevron. Do not classify emulators/games heuristically or invent Add App.
Settings: grouped existing display/recovery/timed-test/diagnostic/permission
controls, with secondary explanations behind information actions. Keep essential
warnings and permissions explicit. Include About/notices/font credits. No false
VRR/refresh locks, boot daemon, fullscreen hook, cache or backup controls.

Controller
Show a compact legend during controller input; hide it on touch. A selects, B
returns, X stops effects immediately, and Y asks to reset the current section
(shader parameters in studio; pattern on BFI). Use circular letter badges and
native focus. These shortcuts apply only inside BFI and its test screen, never
intercept other apps. Browser has no Y reset. Keep list/star controls focusable.

Verification
Run scripts/verify-in-toolbox.sh (debug APK, unit tests, lint), then inspect native
views on the Nova. Preserve original preferences and shader library. Never clear
app data to install an update. Optical timing and physical shader quality are
separate from build/UI checks. No GitHub push or release is implied by UI work.
